## 相对原文的事实修正
1. 退出:原文 §10.3 在读源码后更正过,cgroup_task_exit 只做通知,摘组籍名单在更后面的 cgroup_task_dead。本集按更正后的版本讲(场景 28 只说「pids 要等父进程回收才减一」,不说 cgroup_task_exit 摘名单)。
2. 登记表命名:原文说「核心在建组、入组、fork、退出时按表调用」,本集沿用;表上完整格子是否只有这九种,原文标为待核,旁白只说「按名字筛出来的五个控制器各填了几格」。
3. 超限用语:原文用「撞线」,旁白改成「到上限 / 超限」;日志画面里的「零钱 / 闸门 / 公共池 / 请下场」等旧叫法保持原样,旁白换成「本核额度 / 带宽检查 / 总额度 / 停下」。
4. 原文标为推断或待核的内容(两层开关、透明大页导致缺页次数不同、记账比缺页多的页表页、驱动里「线索已丢」、「一般三到六层」、5 ms 与 64 页的来历细节)旁白均未讲。

除 1~4 外无事实更正;所有数字取自原文。
