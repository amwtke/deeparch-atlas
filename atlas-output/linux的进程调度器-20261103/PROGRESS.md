| # | 短名 | 约束 | 来源 | 逼出的东西 |
|---|------|------|------|-----------|
| C1 | CPU快IO慢 | 核比它要等的东西快 10⁴ ~ 10⁷ 倍,等待是常态 | 物理 | 任务三态、等待时换人、唤醒 |
| C2 | 程序不让台 | 程序不会主动让,内核也猜不到它还要多久 | 程序不可信 + 未来不可知 | 时钟中断、时间片、抢占 |
| C3 | 凭账不凭嘴 | 看不见未来,任务不自报也不可信,只能凭已发生的事 | 信息论事实 | 按已用 CPU 记账、谁欠得多谁先上 |
| C4 | 调度不免费 | 换人直接 1~2 μs + 缓存冷几十 μs;选人代价须与任务数无关 | CPU 微架构 + 无专管调度的核 | 最小运行粒度、公平按周期摊、有序就绪队列、O(log n) 选人 |
| C5 | 核间不通气 | 核与核无共用桌面:跨核共享一行慢几十倍,打断对方慢上千倍 | 缓存一致性 + IPI 代价 | 每核一条队列、亲和、定期均衡 |
| C6 | 有人等不起 | 份额 ≠ 时限:有一类任务要「某时刻前一定拿到」,公平记账只保份额 | 物理世界的期限 | 调度类分家、实时 / 期限优先 |
| C7 | 同机多租户 | 租户在乎的公平单位是「我这一摊」,而租户可随意多开线程 | 应用 / 部署现实 | 组实体 + 子树、cpu.weight / cpu.max(How §6 追加) |
| C8 | 一算法不配万场景 | 负载对三问的最优答案不同,且变化快于内核发布;策略须可换且错了不伤内核 | 应用多样性 + 社区流程 | ext 类 + eBPF 回调表 + DSQ + 看门狗(How §7 追加) |
